## New five-log wave families

The 2026-08-29 five-system loss wave exposed a distinct class of losses that does not begin with an already-falling market. ATB2-R5 adds three pre-Bolt, no-look-ahead topology families:

- **P6 — PEAK -> NO EXTENSION / STALL -> CLIFF**
  - Requires a real prior ascent.
  - Requires measurable near-peak stall time without extension.
  - Requires a material rollover with repeated lower observations before Bolt emission.
  - Works at any price band; it is not a high-price veto.

- **P7 — MICRO BREAKOUT -> REJECTION -> CLIFF**
  - Requires an established prior high with multiple touches over time.
  - Requires only a small breakout above that high.
  - Requires rejection back below the prior high plus material giveback and repeated lower observations.
  - A breakout that holds above the old high remains pattern-clear.

- **P8 — EXTENDED HIGH-ZONE ASCENT -> COMPRESSION/EXHAUSTION -> TERMINAL REVERSAL**
  - Requires a material prior ascent into the high zone.
  - Requires multiple compressed observations near the top.
  - Requires a material reversal with repeated lower observations before Bolt emission.
  - High price by itself can never trigger P8.

P10/SURGE -> PROFITABLE PEAK -> CLIFF remains research-only because its defining evidence is currently post-entry. It is deliberately not added to ATB2 until a causal pre-Bolt precursor is proven.
